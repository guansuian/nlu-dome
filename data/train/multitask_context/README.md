# v10 任务边界与上下文数据

`task_boundaries.jsonl` 新增 1200 条，保留项目现有的换行展开格式。`train.py` 会自动递归读取；其中两种意图都以任务内的 `intent` 为准。

| 内容 | 数量 |
| --- | ---: |
| 多种意图组合：独立查询 | 480 |
| 多种意图组合：局部蚊种指代 | 240 |
| 同种意图多个查询：独立参数 | 120 |
| 同种意图多个查询：共享蚊种 | 120 |
| 多句话但只有一个业务查询 | 180 |
| 多句话且没有业务查询 | 60 |

多任务样本覆盖两至四个任务。新增无时间、仅部分任务带时间，以及明确共享时间的情况；使用问号、逗号、句号、分号、空格或换行连接。训练中的混合意图覆盖全部 22 种顺序组合，双任务中每一种分隔符与无时间/部分时间组合均包含两种意图顺序。

独立查询只标各自明确的条件，不能把上一项的时间自动分给下一项。明确的共享条件在各任务中引用相同原文位置；“这种蚊虫/它”引用前面的具体蚊种，代词自身不作为 `species` 实体。每两项形成一组局部指代时，下一组使用新的蚊种。单任务的礼貌用语和多个句号不会增加任务数。

另有 160 条验证数据和 64 条新测试数据，分别放在 `data/validation/multitask_context/` 和 `data/test/multitask_context/`，使用不同问法模板。原有 78 条测试题及用户反馈的诊断题不放入新增训练集。验证集用于选择检查点，测试集只在最后比较 v9/v10。

全部新增数据检查了结构、实体字符位置、分词对齐、长度、重复、地区层级和意图字段；复核生成句式并抽查各结构代表样本。数据来自人工句式组合，不等同于真实用户语料；模板检查不能排除所有语义近似。

数据冻结记录及逐条类别见 `reports/joint_nlu_v10_data.json`；训练参数与文件指纹见 `reports/joint_nlu_v10_run_manifest.json`（均相对项目根目录）。
